
# 🏎️ Banco de Dados – Fórmula 1

## -Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica durante a graduação em Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é desenvolver um banco de dados relacionado à Fórmula 1, utilizando MySQL para organizar informações, criar tabelas, estabelecer relacionamentos e inserir registros!

## -Tecnologias utilizadas

- MySQL
- SQL
- MySQL Workbench (se utilizado)

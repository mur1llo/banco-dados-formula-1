# -Banco de Dados – Fórmula 1

## -Visão Geral


O objetivo é desenvolver um banco de dados relacionado à Fórmula 1, utilizando MySQL para organizar informações sobre países, equipes, pilotos, corridas e participantes.

O projeto permite praticar a criação de bancos de dados, construção de tabelas, definição de chaves primárias e estrangeiras, inserção e manipulação de registros e consultas SQL.

## -Tecnologias Utilizadas

- MySQL
- SQL
- MySQL Workbench

## -Estrutura do Banco de Dados

O banco de dados possui as seguintes tabelas:

- **paises:** armazena informações dos países.
- **equipes:** armazena informações das equipes de Fórmula 1.
- **pilotos:** armazena informações dos pilotos.
- **corridas:** armazena informações das corridas.
- **participantes:** relaciona os participantes às corridas.

Foram utilizados conceitos de:

- CREATE DATABASE e CREATE TABLE;
- PRIMARY KEY e FOREIGN KEY;
- INSERT INTO;
- ALTER TABLE;
- UPDATE;
- SELECT e consultas SQL.

## -Como Executar o Projeto

1. Instale o MySQL e o MySQL Workbench.
2. Clone este repositório:

   ```bash
   git clone https://github.com/Mur1llo/banco-dados-formula-1.git
   ```

3. Abra o MySQL Workbench.
4. Abra o arquivo `database.sql`.
5. Execute o script SQL.
6. Verifique a criação do banco de dados e das tabelas.
